# 059 — оформление нативного экрана кассовой смены

Причина: стандартные Android Button и фиксированные светлые цвета создавали
монохромный экран, не соответствующий POS. Нативная поверхность использует
палитру существующего POS: фон, карточки, текст, зелёные акценты, красные
действия закрытия/изъятия, скругления и выделение итогов.

Адаптер передаёт только light/dark из data-theme и наблюдает его изменение;
финансовые данные по-прежнему поступают из Room. Бизнес-команды, хранение,
расчёты и формы не изменяются. Откат: MPosNativeShiftScreenEnabled=false.

Автоматические проверки: переключение темы в JS и Kotlin, существующие
проверки действий и расчётов, полный набор тестов, lint и обе APK-сборки.
На планшете остаётся проверить внешний вид обеих тем, размеры текста,
длинные имена и доступность действий. Проверка устройства ещё не выполнена.

Результат: 173 JS и 183 JVM теста прошли; debug/release собраны;
lint: 0 ошибок, 16 предупреждений (новое — рекомендация UseKtx для цвета).
