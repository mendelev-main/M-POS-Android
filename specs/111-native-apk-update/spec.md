# 111 — Нативные метаданные обновления APK и проверки подписи/версии

Статус: planned; подготовлена инфраструктура CI, сам нативный этап пока не завершён.

## Подготовленный фундамент

- Раздельные jobs тестов/lint и сборки; тесты выполняет Actions, агент пишет и поддерживает тесты без обычного локального запуска.
- Постоянный закрытый release-ключ вне Git; публичный SHA-256 сертификата закреплён.
- Автоматическое увеличение versionCode на запуск и повторную попытку.
- Проверка сертификата, package ID, версии и debuggable фактического APK перед публикацией; JSON метаданные и checksum.

Подключение четырёх GitHub Secrets и успешный подписанный CI artifact ещё ожидают выполнения. Подробности: docs/CI_AND_APK_SIGNING_RU.md.

## Оставшийся нативный объём

Получать metadata обновления нативно, показывать текущую/доступную версию, проверять совместимость package ID, подпись и более высокий versionCode перед установкой скачанного APK. Показывать понятные ошибки загрузки/проверки и сохранять рабочую установленную версию. Смена release-ключа без согласованной миграции запрещена. Физические проверки обновления с сохранением данных остаются pending.
