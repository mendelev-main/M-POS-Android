Контракт и размеры текущего окна


Это исходный Web-интерфейс из закреплённого commit, а не HTML-копия Kotlin. Синтетические данные; сеть и внешние действия отключены. Пометка «проверено» хранится только в этом браузере и не является автоматическим доказательством совпадения.


Native-окна без прямого Web-аналога
Проверка обновлений (i), системная установка APK, разрешения Android, выбор файла SAF, стартовое восстановление/ошибки generation, защитная native-копия, дополнительное подтверждение активной кассы, проверка неизвестного результата оплаты/возврата, пересчёт устаревшего заказа и дополнительные подтверждения приёмки/инвентаризации. Для них применяются общие компоненты; пиксельное соответствие несуществующему Web-окну не заявляется.
