## Осознанные native отличия

Durable-ввод теперь сохраняется автоматически; меню черновика убрано по прямому запросу. Retry остаётся контекстным при ошибке, revalidate выполняется перед формированием. Отмена/переход к Приёмке — в карточке заказа, cancel guard сохранён. Правила денег, stock/cost, упаковок и транзакций не переписывались; создание не проводит приёмку. Native status cancelled сохранён отдельно; не выдаём его за Web deleted. Специальная метка Web «Недовоз» ещё требует отдельной связки списка с историческим результатом приёмки, она не подменяется выдуманным сравнением текущих остатков.

## Проверка владельцем

Открыть Историю → Новый заказ → выбрать поставщика → ввести количество/упаковку → свернуть/развернуть оба блока (ввод сохранён) → сформировать → copy/share/done → снова открыть из Истории → редактировать ожидаемый заказ. Проверить админ/кассир, пустого поставщика, упаковку без размера и узкий экран. Предыдущие UI-тесты скорректированы на новые точки входа, audit assertions перенесены в чтение immutable model вместо удалённых технических надписей.
