Новые shared POS-варианты `MposPosControl`/`MposPosIcon` берут path SVG и palette из Web. Общие кнопки редакторов/возвратов не менялись. Нативная оплата вызывает прежние prepare/preview/commit и startSplit: нажатие «Оплатить» сначала сохраняет и проверяет подготовку, затем требуется подтверждение. Это существующий финансовый контракт; он не заменяется прямой записью из Compose. Банковская карта по-прежнему учитывается вручную.

Скидки и ручная доставка сохранены: нажатие строки чека/строки доставки открывает native-параметры оплаты. Их отдельный внешний вид, split P04–P07, подтверждение/готовый чек и подтверждения отложенного заказа C08/C10 пока не перенесены этим инкрементом. Типы/даты/итоги отображаются из native-модели; отсутствующие metadata не выдумываются.

Проверочные снимки формируются с синтетическими данными эталона: P01/P02/P03 light/dark, C09 light/dark + empty. CI явно повторяет два изолированных Compose-теста и забирает PNG перед удалением test APK в `android-ui-reports-api-36/update-e2e`. Основной suite также содержит эти тесты и реальные сценарии оплаты/отложенных чеков. Снимки под скрытыми системными панелями — только стенд для сверки1280×900; production сохраняет safeDrawingInsets.

Статус до CI: source-reviewed/implemented-partial. Автоматические проверки геометрии и наличие PNG не означают pixel-verified. Для закрытия нужны просмотр парных снимков, проверка обеих тем, длинных подписей/списков, размера шрифта и устройства.
