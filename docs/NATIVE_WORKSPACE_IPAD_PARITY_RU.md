# Рабочая зона: перенос визуала iPad в Android

Источник: `prilavok-pos-ipad` commit `67d039c3216a2f4422ca0616074653ccff586107`, `PrilavokPOS/pos.html` и `Web/js/features/cart-presentation.js`, `pos-navigation.js`.

Изменена только нативная рабочая зона. Возвращены плашка «Рабочая зона», расположение «Обычная загрузка» / «Повышенный спрос», «Раскладка» и «Отложенные», ширина корзины из исходной разметки (380 CSS px на широком экране), поля и интервалы сетки. Символ карточки расположен по центру под названием и ценой. В корзине кнопка клиента занимает 44 dp, тип заказа выводится один раз, название товара и сумма находятся в одной строке. Постоянный крестик скрыт; удаление доступно свайпом и accessibility dismiss. «Итого» слева, сумма справа; «Отложить» выше полноширинной «Оплатить». Палитры и размеры шрифта берутся из исходника; остальные экраны не изменены.

Точечное обновление строк, остатков и итогов сохраняется. Новые визуальные параметры не меняют расчёты, хранение, сетевые операции и обработчики оплаты. `MPosNativeWorkspaceSourceLayoutEnabled=false` возвращает предыдущую нативную раскладку; `MPosNativeWorkspaceEnabled=false` — совместимый исходный экран.

Добавлен CI-тест геометрии корзины, положения оплаты, отсутствия дублирования метаданных и сохранения Views при обновлении. Локальные тесты/lint/APK не запускались по указанию пользователя. Синтаксис JS и whitespace проверяются отдельно. Физическая проверка и попиксельное сравнение на одинаковом viewport ещё не выполнены: проверить светлую/тёмную темы, категорию/папку, масштаб шрифта, портрет, свайп, динамические остатки и отсутствие мерцания. Нельзя считать полное визуальное совпадение принятым без этого сравнения.

Это доработка качества этапа 101, без нового завершённого migration ID. Прогресс: 114/129 (88,37%), осталось 15; этап 109 — 7/20 (35%).
