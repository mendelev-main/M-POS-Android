# 107 — нативная аналитика

Синтетические Android/Robolectric compositions с тестовыми данными. Это не
скриншоты HONOR и не физическая приёмка. Общие Manrope/MPosNativeTheme, карточки
показателей, адаптивная сетка, Android даты и нативные диаграммы.

- [Светлая тема](analytics-light.png)
- [Тёмная тема](analytics-dark.png)

Исходник: MPosAnalyticsPresentationTest. Форматирование и ширины диаграмм в
приложении берутся из прежнего renderer с расчётами Kotlin 097. Кассиру не
передаются скрытые суммы выручки сотрудников. Большие диаграммы переиспользуют
видимые строки. Планшетный шрифт/клавиатура/жесты/производительность ожидаются.
