Источник pinned1682c883 pos-navigation.js: ensureLayoutPositions/addLayoutTile/nearestFreeCell/onLayoutPointerUp/reorderPosCategoryTile; tests/source-product-stock.test.cjs navigation/drag cancellation/storage regressions. Главный экран Web хранит до20 плиток с местами, внутри категорий/папок — порядок списка. Native сохраняет это различие;03/оплаты не входят.

Главный экран: до20 плиток категории/товара. До первого пользовательского изменения автоматически показаны категории в текущем порядке и непустая «Без категории» (до20). После настройки добавление категории в каталог не меняет выбранную раскладку; кнопка «Все категории» и поиск сохраняют доступ ко всем товарам. «Добавить плитку» выбирает существующий стабильный ID; дубль запрещён. Удаление плитки не удаляет каталог. Сброс требует подтверждения и возвращает автоматические категории.

HomeTile(type,id,slot) в отдельном workspace_documents/home, payload1/customized. Отсутствующий home создаётся initialize в той же Room transaction без переписывания current/layout/parked, revisions прежних документов сохранены. SQLschema5, cart payload2 и category layout payload1 не меняются. Unknown version/duplicate slots не превращаются в пустую раскладку.

Нативная явная граница:100 мест (UI1–100, storage0–99), до20 занятых; фиксированная логическая сетка5 колонок. При занятой цели выбирается свободная ячейка с минимальной Manhattan distance, затем row/col, исключая переносимую плитку из занятости. Остальные плитки не сдвигаются, старое место остаётся пустым. При более узком viewport линейные номера мест оборачиваются в меньшее число колонок (минимум150dp на плитку), номера/хранение неизменны. Web допускает дополнительные ряды; bounded100 — задокументированное native ограничение.

Внутри категории/папки drag посылает Reorder(type,id,index) только для текущего списка siblings, без пустых мест и перемещения в другую категорию. Прежние «Раньше/Позже» и выбор папки остаются доступной альтернативой. На главном экране нажатие в режиме раскладки открывает номер места и подтверждаемое удаление; доступны Add/Reset. Обычный режим нажатия открывает категорию или конфигурацию товара. Поиск не принимает drag.

Жест: long press, подсветка цели, автопрокрутка у края. Pointer cancel/выход за ячейки/recreate/смена revision или контекста не сохраняют перемещение. До commit показывается прежний документ; ошибка записи/конфликт не переставляет данные частично. CAS(expected home/layout revision), command fingerprint/result/audit атомарны; повтор после lost response не применяет перемещение второй раз. Добавлены delete guards для явно размещённых category/product. Корзина, резерв и физический stock/ledger не меняются.

Проверки:4pure HomeLayout tests (пустоты/nearest free/20 limit/reset/invalid slots/контекст Reorder);2Room (legacy initialize/replay/fault/reopen/unknown payload/concurrent winner/delete guards);1Compose (реальный long-press drag главного экрана, номер места, recreate, category drag).
