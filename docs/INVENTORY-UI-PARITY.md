IV01 implemented: график/периодичность, следующая дата/семидневное окно, внеплановый запуск или продолжение. Поиск/категории/галочки/остатки/сохранение списка; товары без учёта исключены. История50 документов встроена ниже; дополнительный просмотр сводки retained.
IV02 implemented: рабочий экран с группами по категориям, числом товаров и зафиксированных позиций; факт и фиксация прямо в строке. Действия в заголовке: продолжить позже, завершить, крестик отмены. Убраны прежние отдельные окна ввода и подтверждения фиксации.
IV03 implemented: допустимый ввод сохраняется автоматически последовательно после300мс; новый ввод не заменяется результатом предыдущего IO. Перед паузой очередь завершается. Недопустимый/пустой ввод не превращается в ноль и не даёт применить старое значение; требуется исправление. Неподтверждённый результат блокирует новые команды и повторяется исходным commandId. Проверка runtime/revision остатков сохранена.
IV04 implemented: сводка Недостачи/Излишки/Примерный убыток, строки Было/Стало/Разница. Завершение только после фиксации всех строк; завершённый пересчёт возвращает в рабочую зону, отменённый — в настройки пересчёта. Отмена сохраняет фиксации и не откатывает последующие движения (Android adapter).
IV05 implemented: исправление зафиксированной строки. Исходный fix immutable, corrections append-only. Пример: учёт12, факт10, последующее движение−2 (текущий8), исправление факта11 → добавляется+1, текущий9. Повтор команды не добавляет движение ещё раз. Строка и итог недостачи используют последнее исправление; исходное движение по-прежнему открывает документ. Новый пересчёт текущего склада — отдельная инвентаризация.
IV06 implemented: InventoryCodec4 с обязательным массивом corrections, чтение прежних1/2/3 сохранено. SQL schema неизменна. Новые копии с corrections требуют нового приложения; downgrade не заявлен.
IV07 validation: адресные JVM inventory rules/codec/calendar и compile main/Android fixtures; результаты в harness/build-log.md. Room fault/replay и UI/autosave fixtures только компилируются, не запускались на пользовательском планшете.
