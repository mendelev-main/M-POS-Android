## F02 — рабочие незавершённые складские документы

Порядок: ожидаемые закупки → черновики приёмки → активная инвентаризация.

Перенести source IDs, поставщика, строки, единицы/упаковки, введённые и пустые значения, состояние документа и исходное происхождение. Для инвентаризации отличать уже зафиксированные строки от требующих нового пересчёта; не проводить исходные движения повторно и не создавать вымышленные command outcomes. После импорта использовать реальные native revisions и повторно проверять актуальные остатки перед новой записью.

Готовность: заказ10/получено3 закрывается по принятому правилу; превышение12 требует подтверждения; приёмка3шт/10BYN сохраняет стоимость3,33; незавершённая приёмка сохраняет поля и продолжается после перезапуска. Только после этого удалять соответствующие блокировки импорта.
