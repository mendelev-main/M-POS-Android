# Карточка товара: перенос интерфейса Web

Локальная реализация от 2026-11-07. Источник: закреплённый Web, `product-editor.js`, CSS `.product-editor` в `pos.html`; состояния атласа T02/T03/T04. Визуальная приёмка владельцем в Android Studio ещё не выполнена.

Карточка открывается отдельным экраном без каталожной панели. В шапке — «Назад», название и «Сохранить». Слева разделы: основное, состав и остатки, модификаторы, использование, онлайн-меню; удаление снизу. При ширине больше 1100 dp меню занимает 210 dp, сводка справа — 240 dp, промежуток — 22 dp. На меньшей ширине сводка располагается под формой, меню — 190 dp; до 700 dp навигация горизонтальная. Карточка имеет радиус 20 dp, сводка 18 dp, поля 10 dp и минимальную высоту 48 dp. Цвета берутся из общей темы.

Основная форма повторяет порядок Web: название, категория и обозначение, артикул, заметка, тип, цена, фото. Артикул, заметка и обозначение затем подключены: [CATALOG-WEB-PARITY](CATALOG-WEB-PARITY.md). Онлайн-меню относится к отложенному модулю 09. В разделе использования затем подключены прямые/вложенные связи, native-чеки и отложенные заказы; актуальный контракт — CATALOG-WEB-PARITY.md. Тип уже сохранённого товара остаётся неизменяемым по текущему контракту native.

Сохранение, защита несохранённых изменений, удаление, остатки, рецептуры, модификаторы и фото используют существующие обработчики. Сводка пересчитывается из черновика без записи данных; себестоимость учитывает единицу отображения и выход рецептуры. Схема хранения не менялась.

Адресные JVM-тесты ProductEditorCostTest покрывают перевод стоимости грамма в килограмм и стоимость составного товара с выходом рецептуры. Существующие UI-сценарии каталога адаптированы к навигации разделов и названиям кнопок фото; их исполнение на устройстве и визуальное подтверждение — отдельно. Статус T02/T03/T04 — partial, без заявления попиксельного соответствия.
