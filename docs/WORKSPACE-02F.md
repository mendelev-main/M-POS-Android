# Рабочая зона02f — большой каталог, фото, адаптивность

W01/W03/W07 и DS04: производительность проекций, ограничение памяти thumbnail, ориентация/150% шрифт на disposable Android16/API36 emulator. mpos-phase/mpos-domain. Платёжный этап03 не входит; физические планшеты/OEM остаются отложенными пользователем. Источник поведения pinned1682c883 pos-navigation.js renderPosScreen/posDisplayStock и android-pos-stock.js reservationSnapshot/checkedStockConsumption. Оптимизация не меняет формулы расхода/резерва.

До02f Compose строил RecipeCalculator и пересчитывал текущую корзину/parked для каждого товара всего каталога. Теперь WorkspaceAvailability формируется на background IO при публикации snapshot: общий calculator/byId/current requests/parked reserves, затем thread-safe cache статуса только запрошенных product IDs. Lazy обработчик добавления получает актуальный snapshot/owner через rememberUpdatedState после park/resume; прежний owner не захватывается надолго. Lazy плитки запрашивают статус на Dispatchers.Default. Публикации UI состояния выполняются на Main.immediate, расчёт index остаётся IO. Новый snapshot каталога/корзины/остатков/parked создаёт новый index; смена только раскладки переиспользует прежний. Подпись advisory: Add/increase по-прежнему транзакционно проверяются CartEngine; cache не даёт разрешение продажи и не пишет склад. Неизвестный/невалидный graph даёт явный «Требуется проверка состава».

Поиск/проекция списка — Default с cancellable produceState и ключом результата: старые результаты не показываются под новым запросом/контекстом. Главный выбор категории/товара — LazyColumn вместо composition всего каталога. LayoutEngine.project использует set размещённых ID вместо nested scan; recipe/components и modifier/groups/options индексируются по owner/group вместо многократного filter. SQLschema5/payloads не меняются.

Фото: закреплён Coil3.3.0/coil-compose, один application ImageLoader, MemoryCache16MiB, request256px, без сетевого модуля и duplicate disk cache. Только File из ProductPhotoStore.file(id) с прежней проверкой UUID; immutable private JPEG/600KB/1200px подготовка и fsync/store semantics прежние. AsyncImage без Subcompose на Lazy плитках; productPhoto test tag появляется после реального decode Success, error не показывает прежнее изображение. ProductPhotoStore.read остаётся низкоуровневым adapter для прежних tests/fixtures.

Официальные API: [Coil Compose](https://coil-kt.github.io/coil/compose/), [shared ImageLoader/cache](https://coil-kt.github.io/coil/image_loaders/). Используется pin3.3.0, не заявление об актуальной latest версии. Учитывается рекомендация AsyncImage и shared loader; актуальные docs показывают другую latest версию, проект не обновляет её автоматически.
