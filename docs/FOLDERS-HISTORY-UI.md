## Хранение и резервная копия

FolderAppearance хранится в LayoutItem только для folder. SaveFolder без appearance сохраняет существующее оформление, чтобы старый caller переименования его не сбросил. Новый fingerprint включает все поля оформления; прежний command fingerprint без appearance сохранён. Валидация цвета/графем/колонок/высоты выполняется в domain/repository, не только UI. Раскладка записывается одной прежней layoutTransaction, прав на администрирование не требует, остатков/сумм/сессий не меняет.

WorkspaceCodec сохраняет layout v1 при стандартном оформлении и v2 при наличии настроек. Decoder принимает1/2, строго проверяет поля и запрещает оформление product. Старые Web/native папки получают auto/default144/без цвета/пустой символ. Native backup содержит workspace_documents; NativeRestoreValidator использует тот же decoder. Схема Room/общий формат архива/подпись приложения неизменны. Полный native backup restore v2 на планшете ещё не выполнялся; проверен roundtrip payload.

ReceiptHistoryShell вынесен над lifecycle/loading gate: при ожидании, обновлении и ошибке меняется только тело. Shell и тело используют общий saleNavigationLocked, сохранены блокировки финансовых операций. Оплата продолжает использовать свой экран.
