Дата печатного чека — SHORT/SHORT текущей locale, как у Web Android; формат прочих экранов/Telegram не меняется.

Растровая ESC/POS команда GS v0, порог180; перед отрезкой один LF, как у Web. Init/cut остаются настраиваемыми. Web Android реально растеризует и при legacy printMode=text: native использует тот же графический путь, чтобы выбор режима не менял шрифт/геометрию. DPI сохраняется как совместимое поле и не масштабирует bitmap, как в Web Android. Для совпадения бумаги использовать auto width; существующий явный override384/576 сохранён. Диагностическая тестовая страница native не является платёжным чеком.

Сохранённые денежные суммы не заменяются вычислениями Double из Web. Принятый HALF_UP по строкам остаётся. Подарок лояльности выделяется отдельной строкой программы; сумма оплаты не меняется. Подтверждённый progress печатается кружками по12 в строке с приоритетом events, как Web. Неподтверждённое начисление не печатается как подтверждённая акция. Дробные количества обычно форматируются двумя знаками как Web, но допустимые ненулевые количества меньше0.005 сохраняют точность вместо ложного нуля (существующий инвариант native).

Финансовая транзакция и snapshot не меняются. Печать только после сохранения; durable claims, отсутствие автоматического повтора при неизвестном исходе, копии, фильтр кухни и cash-only ящик сохраняются. Физическое совпадение ещё требует двух образцов с одинаковыми настройками принтера/locale/данными.
