# История смен и сводка кассы

Решение владельца2026-11-08: история хранится без ограничения365 днями и остаётся доступной целиком. Старые смены, чеки и связи не удаляются. Первоначальное предложение годового окна отменено уточнением владельца.

## Загрузка

- Начальная страница:10 закрытых смен. «Показать10 предыдущих» добавляет следующие10; последняя страница может быть короче.
- Ключ страницы — дата закрытия и ID, по убыванию. Запрос читает11 строк:10 для отображения и одну для определения продолжения. OFFSET не используется, одинаковые даты не создают пропусков/дубликатов.
- Полные данные смен, продаж и возвратов выбираются только для текущей страницы и открытой смены. Для сохранения прежней сквозной нумерации отдельно читаются лёгкие поля ID/дата открытия/предыдущая смена, без чеков и других payloads.
- Сводка активной смены независима от страницы. Уже показанные страницы остаются на экране. Изменение кассового состояния/обновление экрана возвращает историю к последним10; устаревший ответ подгрузки не добавляется к новой сводке.
- Ошибка подгрузки не удаляет показанные строки; кнопку можно нажать повторно. Все отчёты загруженных смен открываются из списка.
- Ручные движения наличных пока хранятся единым JSON-журналом: текущая проверка этого журнала сохраняется. Это отдельная модель хранения; её построчная индексация при большом объёме потребует отдельной миграции. Пагинация не означает, что этот журнал уже мигрирован.

## Расположение

«Итоги продаж» и «Выручка» расположены рядом в первой строке сводных блоков, одинаковой ширины. Ниже расположен полноширинный блок «Наличные в кассе». Использованы существующие стили секций, выравнивание сумм и выделение ожидаемой суммы. История — ниже сводки и действий смены.
