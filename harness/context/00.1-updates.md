# Контекст 00.1 — 2026-10-24

Цель: собственный APK update flow для обычного Android-планшета, с подтверждением Android. Источник — публичные GitHub Release assets, не временные Actions artifacts. Постоянный release signer/package уже закреплены в config/android-release.json. Новые ключи не создаются.

UI/загрузка: ViewModel + coroutines, OkHttp; bootstrap не требует внедрения Room/Hilt всего будущего приложения. Проверенный APK хранится в закрытом files/updates и передаётся системному установщику через FileProvider с временным read grant. Версия после restart читается из PackageManager, а не из результата закрытия установщика. Скачивание по действию пользователя; проверка при открытии настроек.

Debug-only fixture source ограничен localhost/loopback и фиксированным адресом хоста Android Emulator 10.0.2.2; release не принимает endpoint из Intent. Эмулятор использует debug APK одного signer и реальный системный installer: процесс приложения может быть заменён, поэтому тест управляется извне через adb/UIAutomator XML. Production cert проверяется отдельно в signed CI и release manifest.
