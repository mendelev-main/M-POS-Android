## Уточнение владельца: меню печати истории и админ-индикатор
В истории нажатие «Печать» теперь открывает компактный выбор двух документов: «Печатать чек» (RECEIPT, прежний шаблон) / «Печатать заказ» (KITCHEN, приготовление без сумм). Выбор отправляет напрямую по existing manual routing/copies; закрытие не печатает. Это явное новое правило владельца, заменяет отсутствие любого модального окна для истории в предыдущей задаче. Текущий счёт из трёх точек печатается напрямую, как прежде.

В верхнем меню показывается тот же admin shield, что в настройках, зелёные фон/рамка/значок44dp; только при runtime adminActive, без отдельного режима/прав. Выход из сессии убирает индикатор сразу.

Возвращённый чек: компактная красная метка «Возврат»/полные дата и время в header справа; большой баннер внутри документа удалён. Footer только «Печать», никаких возвратов/исправлений оплаты. Исходный чек/возврат/суммы не изменяются. Подтверждение возврата: отдельный блок суммы/наличные/карта/возврат курьерского расхода, одинаковые48dp кнопки.
