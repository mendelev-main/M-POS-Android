# 11.11.2026 — Управление и настройки UI

По явному запросу владельца новый нативный справочник в панели администратора: одна постоянная запись собственника, добавляемые плюсом контакты администраторов, редактирование по нажатию. Для каждого — телефон, почта, Telegram ID. Это контакты, а не сотрудники, пароли или роли; runtime admin session и существующие настройки Telegram не меняются, рассылок из этих полей пока нет.

Хранение: один versioned Room WorkspaceDocument management.contacts.v1, owner ID owner, стабильные UUID администраторов, revision compare-and-set. Административная транзакция + InstallationGate, проверка исходной generation сессии внутри транзакции; отказ/устаревшая форма/выход и повторный вход не переписывают сохранённые данные. UI modal с явным сохранением, исходная форма при ошибке сохраняется, список обновляет Room Flow. Добавление/редактирование не меняет порядок других записей. Пустые контактные поля допустимы, почта и числовой Telegram ID проверяются. Лимиты100администраторов/64телефон/254почта/64ID. Нельзя удалить/заменить ID собственника. Отдельной операции удаления владелец не запрашивал.

Это новый native модуль, Web формата этих контактов пока нет; перенос их из Web и использование для отправок не заявляются. Чтобы новый документ не ломал существующую native-копию, он добавлен в whitelist NativeRestoreValidator с обязательным codec validation. NativeBackupTest seed теперь включает контакты, существующий roundtrip сверяет все documents. Это compile-only регрессия до CI/device прогона, не заявление о проверенном восстановлении.

Дополнительно R01: receiptDate содержит год; header return sticker — одна строка «Возврат · дата время», radius100 как метки истории. Нижний padding страницы0; панели только с верхним radius22, низ прямой до края, включая read-only Web receipt. Online — новое имя карточки/диалога backend, настройки/маршруты/ключи не меняются. Все status strips NetworkCard fillMaxWidth, в том числе Online/Telegram.

Применены mpos-phase/mpos-domain. Тесты: codec JVM + Room durable/stale/rollback/logout/relogin; расширены receipt layout assertions. Device UI acceptance владельцем pending. Работа локально без push.

Уточнение: Управление теперь стандартный AdminModuleCard в сетке, отдельная full-screen страница «Руководитель». Все owner поля сразу доступны; добавленные администраторы ниже, общее атомарное сохранение. Новый интерфейс читает прежний management.contacts.v1 без миграции. Глобальные shield/settings/logo возвращают на корень соответствующего раздела; reselect обработан navigationRequest.
