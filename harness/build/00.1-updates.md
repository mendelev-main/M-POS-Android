# Этап 00.1 — обновление приложения

Статус: in-progress. Авторизовано пользователем 2026-10-24. Зависимость: 00; товары/продажи не входят.

- U01: Настройки → Обновления: текущая версия, проверка, новая версия/описание, отсутствие обновлений, offline/error и повтор.
- U02: Ограниченная по размеру загрузка, прогресс/отмена; незавершённый APK не предлагается к установке.
- U03: SHA-256, размер, package, minSdk, versionCode/versionName и pinned signer проверяются до установки и повторно перед ней. Downgrade/чужой package/сертификат отвергаются.
- U04: Системное разрешение внешних установок и installer confirmation; отмена не считается успехом. Restart восстанавливает проверенный APK, после успешного обновления показывается фактическая установленная версия.
- U05: CI builds остаются artifacts; ручной publish_release выпускает проверенные APK/update.json в GitHub Releases. Stable указатель обновляется последним; токен не входит в APK.
- U06: JVM/instrumentation regressions + emulator self-update 1→2 с системным подтверждением, проверкой отмены и сохранённого файла. Физическая приёмка на планшете отдельно.

Контекст: harness/context/00.1-updates.md. Evidence: harness/build-log.md. Установку инициирует только пользователь. В bootstrap нет незавершённых кассовых операций; при добавлении 03 запрет установки во время commit должен подключаться к доменному состоянию.
